# HAID Project Management — sitio web

Sitio estático de una sola página (`index.html`) con sus imágenes en `assets/img/`.

Para verlo, abre `index.html` en el navegador. No necesita compilación.

Formulario de contacto: Formspree, formulario `mzeegqbj`. Los mensajes llegan al correo
con el que se creó ese formulario en formspree.io.

Google Analytics 4: `G-E1B6F3FZD6`. Cada formulario enviado con éxito registra el evento
`generate_lead` (con `servicio` y `sector`); márcalo como evento clave en GA4.
